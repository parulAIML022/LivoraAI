## Can I connect a custom domain to my LivoraAI project?

Yes, you can!

To connect a domain, navigate to Project > Settings > Domains and click Connect Domain.

Read more here: [Setting up a custom domain](https://docs.LivoraAI.dev/tips-tricks/custom-domain#step-by-step-guide)
